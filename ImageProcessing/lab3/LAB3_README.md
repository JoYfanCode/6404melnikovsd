# Лабораторная работа №3

## Описание

Анализ данных о видеоиграх из CORGIS Dataset Project. Вариант 3.

## Требования

- Python 3.11+
- pandas
- numpy
- matplotlib
- scipy
- pyarrow

## Установка зависимостей

```bash
pip install pandas numpy matplotlib scipy pyarrow
```

или через pipenv:

```bash
pipenv install pandas numpy matplotlib scipy pyarrow
```

## Подготовка данных

1. Скачайте файл `video_games.csv` с сайта CORGIS Dataset Project:
   https://corgis-edu.github.io/corgis/csv/video_games/

2. Поместите файл в корневую директорию проекта (рядом с `main_lab3.py`)

## Использование

### Базовый запуск (все задачи)

```bash
python main_lab3.py --csv-file video_games.csv
```

### Указание размера чанка

```bash
python main_lab3.py --csv-file video_games.csv --chunksize 5000
```

### Изменение окна скользящего среднего

```bash
python main_lab3.py --csv-file video_games.csv --window 5
```

### Пропуск определённых задач

```bash
# Пропустить только задачу 4 (Parquet)
python main_lab3.py --csv-file video_games.csv --skip-task 4

# Пропустить несколько задач
python main_lab3.py --csv-file video_games.csv --skip-task 2 4
```

## Задачи

### Задача 1: Агрегация данных
**Лучший и худший годы для игровой индустрии с точки зрения продаж (Sales)**

- Агрегирует продажи по годам
- Находит год с максимальными и минимальными продажами
- Выводит график: Line plot с выделением лучшего и худшего года

**Результат:** `lab3_task1_sales_by_year.png`

### Задача 2: Дисперсия и доверительный интервал
**3 издателя с наибольшим и 3 с наименьшим разбросом оценки игр (Review Score)**

- Вычисляет дисперсию оценок для каждого издателя
- Строит доверительные интервалы (95%)
- Выводит график: Bar plot с доверительными интервалами

**Результат:** `lab3_task2_publishers_variance.png`

### Задача 3: Изменение значения во времени и скользящее среднее
**Общее количество выпущенных игр каждого возрастного рейтинга (Rating: E, T, M) в каждом году**

- Агрегирует количество игр по рейтингам и годам
- Вычисляет скользящее среднее (окно=3 по умолчанию)
- Выводит график: Line plot с фактом и скользящим средним

**Результат:** `lab3_task3_ratings_by_year.png`

### Задача 4: Дополнительное задание (Parquet)
**Корреляция между оценкой игры (Review Score) и заработанной на ней суммой (Sales)**

- Конвертирует CSV в Parquet формат
- Сравнивает скорость чтения CSV и Parquet
- Вычисляет корреляцию из Parquet (чтение только нужных столбцов)
- Выводит график: Scatter plot с линией тренда

**Результат:** `lab3_task4_correlation.png` и `video_games.parquet`

## Архитектура

### Генераторы (lab3/generators.py)
- `read_csv_chunks()` - чтение CSV по частям
- `extract_sales_data()` - извлечение данных о продажах
- `extract_review_data()` - извлечение данных об оценках
- `extract_rating_data()` - извлечение данных о рейтингах
- `extract_correlation_data()` - извлечение данных для корреляции

### Модули задач
- `task1_aggregation.py` - агрегация продаж по годам
- `task2_variance.py` - дисперсия оценок по издателям
- `task3_time_series.py` - временной ряд по рейтингам
- `task4_parquet.py` - работа с Parquet и корреляция

### Визуализация (lab3/visualization.py)
- `plot_task1()` - график продаж по годам
- `plot_task2()` - график издателей с доверительными интервалами
- `plot_task3()` - график рейтингов со скользящим средним
- `plot_task4()` - scatter plot корреляции

## Параметры командной строки

- `--csv-file` - Путь к CSV файлу (по умолчанию: `video_games.csv`)
- `--chunksize` - Размер чанка для чтения (по умолчанию: 10000)
- `--window` - Размер окна для скользящего среднего (по умолчанию: 3)
- `--skip-task` - Пропустить выполнение указанных задач (1, 2, 3, 4)

- Программа использует генераторы для обработки больших файлов

- Для визуализации больших данных используется выборка (до 10000 точек)
